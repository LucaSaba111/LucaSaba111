# Luca Sabatini

IT consultant based in Cosenza, Italy. I integrate systems and build software that is ready to use on day one: web apps, websites, management tools and AI systems, for local businesses, professionals and public bodies.

I come from cybersecurity, so security, privacy, GDPR and the EU AI Act are part of the design from the start, not something added at the end. I work mostly remotely, across Italy.

What I work on:

- Integrations with Italian public-sector and healthcare systems
- Custom web apps, internal tools and APIs
- Applied AI: LLMs, RAG and agents, tested for cost and limits before they reach a client
- Security reviews and hardening for small businesses

Stack: Python, TypeScript, React, PostgreSQL, Linux.
